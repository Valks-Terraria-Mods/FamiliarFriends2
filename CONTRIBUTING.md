## Compiling and using the mod
1. Install .NET SDK 8 from https://dotnet.microsoft.com/en-us/download/dotnet/8.0
2. Find the location of the tModLoader mod sources folder. In tModLoader Main Menu click on > Workshop > Develop Mods > Open Sources. This will open your file explorer app to the location of where this mod should go. For example for me it's at `/home/tiger/.local/share/Terraria/tModLoader/ModSources/`.
3. Clone this repo to that mod sources folder. I highly recommend using GitHub Desktop. You can install this on Windows and Linux. **If you need help with this, please message me over Discord my username is valky5.**
4. Rename the folder of the mod from `FamiliarFriends2` to `FamiliarFriends` (this is important!)
5. Click `Build + Reload` for the FamiliarFriends mod in the Workshop > Develop Mods menu.
6. You are done. The mod should be enabled and you should be able to play around with it in singleplayer.
